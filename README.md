# Apps and Tools

Soraironezu Labが作成した小規模なアプリやツールの配布用リポジトリです。

## 配布中のアプリ

### ChatSwitch

macOS上でCodexの複数チャットの状態を一覧で確認し、次に戻るチャットへ切り替えるための補助アプリです。

- [ChatSwitchの説明・動作環境・利用条件](chatswitch/README.md)
- [GitHub Releasesからダウンロード](https://github.com/soraironezu-lab/apps-and-tools/releases)

配布ファイルは、このリポジトリのGitHub Releasesに添付されたものだけを公式な配布物として扱います。
