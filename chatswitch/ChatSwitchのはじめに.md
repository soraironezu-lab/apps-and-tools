# ChatSwitchをはじめる

この配布ファイルには、アプリ識別のためのアドホック署名だけを行い、Developer ID署名・公証を行っていないβ版アプリが含まれています。Apple Silicon搭載Mac（macOS 26.5以降）専用で、Intel Macには対応していません。公式Releaseからダウンロードしたファイルであることを確認してから進めてください。

このβ版はVoiceOverでの主要操作には対応していません。VoiceOver利用が必要な方には、現時点では利用をおすすめしません。

## 1. アプリをコピーする

`ChatSwitch.app`を`Applications`フォルダへドラッグします。

## 2. 初回起動する

`Applications`からChatSwitchを開きます。macOSの警告で起動できない場合は、最初の警告で「ゴミ箱に入れる」ではなく「完了」を選びます。「システム設定 → プライバシーとセキュリティ」でChatSwitchの許可操作を選び、ChatSwitchをもう一度開きます。確認ダイアログで「このまま開く」を選び、求められた場合は管理者のユーザ名とパスワードで許可します。

警告内容を理解できない場合や、公式Release以外から入手した場合は起動しないでください。

## 3. macOS通知を確認する

ChatSwitch内の通知設定と、macOSの通知許可は別の設定です。初回起動時にmacOSの通知許可ダイアログが表示されない場合があります。

通知が届かない場合、または許可ダイアログが表示されなかった場合は、「システム設定 → 通知 → ChatSwitch」を開き、「通知を許可」をオンにしてください。必要に応じて通知音やバッジも同じ画面で設定できます。この操作で変更されるのは、現在のmacOSユーザーの通知設定だけです。

macOS側の通知許可がオフでも、ChatSwitch内のチャット一覧と未確認状態は更新されます。

## 4. Codex Hooksを設定する

Hooksは即時反映のための任意機能です。設定しなくてもチャット一覧とチャットへの復帰は利用できます。

1. ChatSwitchの「設定 → Codex連携」を開きます。
2. 「自動設定の内容を見る…」で追加内容を確認して自動追加するか、「手動設定の手順を見る…」で自分で設定するか、どちらか一方を選びます。
3. Codexで`/hooks`を入力します。
4. ChatSwitchの6項目について、イベント名とコマンドを自分の目で確認してから信頼します。
5. Codexで新しい作業を開始し、ChatSwitchに状態が反映されることを確認します。

自動設定では、ChatSwitchが追加前の`~/.codex/hooks.json`をバックアップします。ChatSwitch以外のHookは変更しません。手動設定の詳しい追加・確認・削除方法は、同梱の`ChatSwitch-Hooks手動設定.md`を参照してください。

## 困ったとき

- 状態がすぐ反映されない: Codexの`/hooks`でChatSwitchの項目を信頼済みにしているか確認してください。
- Hooksをやめたい: 自動設定した場合はChatSwitchの「設定 → Codex連携 → Hooksを削除…」を使います。手動設定した場合は`ChatSwitch-Hooks手動設定.md`に従って同じ6項目を手動削除します。
- 不具合を見つけた: 配布リポジトリのIssuesへ、macOS・ChatSwitch・Codexのバージョンと再現手順を添えて報告してください。Webhook URLやチャット本文は投稿しないでください。
