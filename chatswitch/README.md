# ChatSwitch β版

ChatSwitchは、macOS上でCodexの複数チャットの状態を一覧で見渡し、次に戻るチャットへ切り替えるための補助アプリです。

これは **ChatSwitch 0.1.0-beta.1** のβ版です。実際の利用を通して、作業状況の把握とチャットの切り替えが役立つかを確かめる目的で配布しています。

## 必要なもの

- macOS 26.5以降
- Apple Silicon搭載Mac（Intel Macは非対応）
- CodexデスクトップアプリまたはCodex CLIを利用できる環境
- Codex Hooksを確認・信頼するためのCodex操作

## インストールと初回設定

1. ダウンロードしたZIPを展開し、`ChatSwitch.app`を`Applications`フォルダへコピーします。
2. `Applications`からChatSwitchを開きます。
3. macOSにより起動を止められた場合は、最初の警告で「ゴミ箱に入れる」ではなく「完了」を選びます。「システム設定 → プライバシーとセキュリティ」でChatSwitchの許可操作を選び、ChatSwitchをもう一度開きます。確認ダイアログで「このまま開く」を選び、求められた場合は管理者のユーザ名とパスワードで許可します。内容を理解できない場合は起動しないでください。
4. 初回起動時にmacOSの通知許可ダイアログが出ない場合、または通知が届かない場合は、「システム設定 → 通知 → ChatSwitch」で「通知を許可」をオンにします。ChatSwitch内の通知設定とmacOSの通知許可は別の設定です。
5. ChatSwitchの「設定 → Codex連携」で、自動設定または手動設定のどちらか一方を選びます。
6. 追加前に、対象の6イベントと完全な実行コマンドを確認します。
7. Codexで`/hooks`を開き、ChatSwitchの6項目を自分の目で確認してから信頼します。
8. Codexで新しい作業を1件開始し、ChatSwitchに状態が反映されることを確認します。

自動設定では、現在の`~/.codex/hooks.json`がバックアップされます。手動設定の詳しい追加・確認・削除方法は、ZIPに同梱する`ChatSwitch-Hooks手動設定.md`に記載しています。

## できること

- Codexチャットの一覧と状態を確認する
- 作業中、確認待ち、完了などの状態を表示する
- 一覧から既存のCodexチャットを開く
- 同じ作業フォルダで新しいCodexチャットを始める
- プロジェクト単位でチャットを表示・検索する
- macOS通知、メニューバー、Dockバッジで状態を確認する
- 任意でDiscord Webhookへ通知する

## β版の制約・未実装

- Developer ID未署名・未公証のため、初回起動時にmacOSの警告が表示されます。
- Apple Silicon搭載Mac専用です。Intel Macでは利用できません。
- 即時の状態反映には、利用者自身がCodexの`/hooks`で内容を確認・信頼する必要があります。
- Codex以外のAIコーディング環境との連携、Claude Code連携は未実装です。
- ChatSwitchからプロンプト送信、エージェント起動、権限操作、コード変更は行いません。
- 自動更新、バックグラウンド更新、クラッシュレポートの自動送信は行いません。
- 状態の短時間の変化は、まれに反映できない場合があります。
- Hooksを設定していない場合でも、一覧画面に「Hooksで即時更新」と表示されます。Hooks未設定時は即時更新が有効になっていることを示す表示ではありません。
- 通知設定ウィンドウが、ほかのアプリのウィンドウの背面に開く場合があります。表示されないときは、Dockまたはアプリ切り替えでChatSwitchを選択してください。
- 初回起動時にmacOSの通知許可ダイアログが表示されない場合があります。通知が届かない場合は、「システム設定 → 通知 → ChatSwitch」で許可状態を確認してください。許可がオフでもアプリ内の一覧と未確認状態は更新されます。
- VoiceOverでの主要操作はこのβ版では対応していません。VoiceOver利用が必要な方には、現時点では利用をおすすめしません。

## データとプライバシー

- チャット本文とモデルの思考内容は保存しません。一覧の復元と再開に必要な作業フォルダのパスはMac内に保存します。
- Discord通知は、利用者がWebhook URLを設定して有効にした場合だけ送信します。
- ChatSwitchの設定やローカルデータは`~/Library/Application Support/ChatSwitch/`に保存します。
